# TouristResort
Java console application for the management of tourist destinations (Thessaloniki, Patras), which provides information on itineraries, attractions, dining and accommodation, facilitating the completion of reservations by users.

# Tourist Resort Management System

A Console Application developed for the MSc in Informatics, designed to manage travel information, attractions, and reservation processes for tourist destinations in Greece (Thessaloniki and Patra).

## Features
The application provides an interactive menu that allows users to explore and plan their trips.

* **User Registration:** Allows users to input their personal details (full name, phone, email) to initiate a booking.
* **Route Planning:** Calculates the estimated travel cost and duration from Athens to Thessaloniki or Patra.
* **Points of Interest (POI):** Displays landmarks, museums, and monuments, including ratings, entry fees, and user comments.
* **Dining Options:** Recommends top-rated restaurants in each city, providing average meal costs.
* **Accommodation:** Provides information on hotels and resorts, including star ratings and cost per night.
* **Comparative Analysis:** Estimates the total cost of visiting each destination (including route, POI fees, accommodation, and food) to help users identify the most budget-friendly option.
* **Reservation System:** Enables users to select a destination, choose a resort, input the visit date, and finalize their reservation.

## Tech Stack
* **Language:** C#
* **Type:** Console Application (CLI)

## Usage
1. Clone the repository: `git clone https://github.com/DimZarifopoulos/TouristResort.git`
2. Open the project in Visual Studio.
3. Build and run the application.
4. Follow the on-screen prompts to register your info and select your preferred destination.
